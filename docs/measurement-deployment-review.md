# Measurement Deployment Review

## Status

This document is the planned location of the PRECONDITIONS and SAFETY human review cases of the nine measurements. Their reviewer roles, reviewed artifacts and checklists are in the [measurement case plans](measurement-requirements.md#planned-cases-and-requirement-dispositions); the table below records, for each case, what blocks the review.

No case has been reviewed, and every case stays `planned`. The artifacts these cases review do not exist yet: no native Android or Apple adapter revision has been designated and reviewed, and no host scheduling and consent integration, deployment target list or registration, or deployment documentation exists, because no host application or deployment is in scope. A review case also cannot change status before the review-record format decision of [Typed Review Cases](traceability-manifest.md#typed-review-cases): the public format links only `conformance` evidence from a case, so a review record needs that decision first. When a review is performed, its record goes under a heading equal to the case ID, which is the case's manifest location.
